MY WARDROBE V3 — FREE IPHONE APP

Update your existing GitHub repository by replacing index.html and sw.js with the files in this ZIP. You can also upload README-V3.txt. Keep icon files and manifest.webmanifest unchanged.

Your existing wardrobe uses the same IndexedDB database, mywardrobe-private-v1. Updating the app files will not intentionally delete your existing items. Before updating, export a backup using More > Export backup.

NEW: Auto-suggest (approximate dominant garment color + editable item name based on selected category); Quick cleanup (simple plain-background removal, works offline); Remove background (AI) on device with an open-source library downloaded from esm.sh and model assets downloaded from IMG.LY. External downloads require internet, and the AI cleanup might fail on Safari due to device limits or browser compatibility. No paid APIs or subscriptions. Brand and fabric are not identified automatically.

The original source photo may be kept for restoration. Large photo libraries can use device storage. Use Export backup regularly.

Background removal library: @imgly/background-removal, AGPL-3.0, https://github.com/imgly/background-removal-js . Source repository should remain public to comply with license conditions.
